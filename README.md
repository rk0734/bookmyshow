🎬 BookMyShow Clone – Movie Ticket Booking App

A modern movie ticket booking web application that allows users to browse movies, select theaters, choose seats, and manage bookings.

🚀 Features

🎥 Browse currently showing movies

🏢 Select theaters & show timings

💺 Interactive seat selection

🔐 User authentication

📖 Booking history & management

📱 Responsive design for all devices

🛠 Tech Stack

Frontend

React

TypeScript

Vite

Tailwind CSS

shadcn/ui

Backend & Services

Supabase (Authentication & Database)

📦 Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/rk0734/bookmyshow.git

2️⃣ Navigate to project folder
cd bookmyshow

3️⃣ Install dependencies
npm install

4️⃣ Add environment variables

Create a .env file and add:

VITE_SUPABASE_URL=your_url
VITE_SUPABASE_ANON_KEY=your_key

5️⃣ Run development server
npm run dev


Open:

http://localhost:5173
